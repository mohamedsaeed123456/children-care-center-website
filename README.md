# Children's Care Center Website

A responsive website for a community children's care center in Saudi Arabia, built with native PHP, JavaScript, HTML and CSS. It presents the center's services and programs to parents and families and lets visitors send enquiries.

> Built as a freelance project for a Saudi client. This is an early project from my career, written in native PHP without a framework.

## Features

- Responsive layout that works on mobile, tablet and desktop
- Pages presenting the center, its services and programs
- Contact and enquiry form handled by a PHP backend
- Simple, clean and easy-to-navigate interface for parents and families

## Tech Stack

| Layer    | Technology                |
| -------- | ------------------------- |
| Backend  | Native PHP                |
| Frontend | HTML5, CSS3, JavaScript   |

## Getting Started

### Requirements

- PHP 7.4 or later
- Apache web server (XAMPP, WAMP, Laragon, or similar)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mohamedsaeed123456/children-care-center-website.git
   ```

2. Move the project folder into your web server directory (for example `htdocs` in XAMPP).
3. If the project uses a configuration file for the contact form or email settings, copy the example file and fill in your own values. Never commit real credentials.
4. Start Apache and open `http://localhost/children-care-center-website` in your browser.
